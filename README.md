# KPI project website

This is the named KPI project site for [TToTMooN/KPI](https://github.com/TToTMooN/KPI). It is a separate repository and checkout from the anonymous [robot-kpi/robot-kpi.github.io](https://github.com/robot-kpi/robot-kpi.github.io) site.

The initial site content was copied from the anonymous site's `c25ae0d` revision on September 25, 2026, then updated with the authors, affiliations, and named paper. Only media referenced by the page was copied, so the published site stays within GitHub Pages' 1 GB limit. Future edits to either site are independent.

The site uses relative asset URLs and no project-level `CNAME`. Once GitHub Pages is enabled for this repository, it inherits the `lingfeng.moe` custom domain configured on the `TToTMooN.github.io` user site and should be served from `https://lingfeng.moe/KPI/`.

The local paper file at `assets/kpi-paper.pdf` is the 11-page named release PDF from the KPI paper workspace. Replace it when a newer public version is available.
